# MAT-OPTIM AI — Prototype MVP

## التشغيل محلياً
1. ثبّت Python 3.10 أو أحدث.
2. افتح Terminal داخل مجلد المشروع.
3. أنشئ بيئة افتراضية (اختياري):
   `python -m venv .venv`
4. فعّل البيئة:
   - Windows: `.venv\\Scripts\\activate`
   - macOS/Linux: `source .venv/bin/activate`
5. ثبّت المتطلبات:
   `pip install -r requirements.txt`
6. شغّل التطبيق:
   `streamlit run app.py`

## محتويات المشروع
- `app.py`: واجهة Streamlit والوظائف الأولية.
- `data/materials.csv`: قاعدة بيانات تعليمية أولية.
- `requirements.txt`: المكتبات المطلوبة.

## ما الذي يعمل في هذه النسخة؟
- واجهتا Mode Simple وMode Expert.
- فرز المواد بمعايير أولية.
- عرض بطاقات المواد واستخداماتها وطرق تصنيعها.
- فرز بدائل أولية.
- حاسبة إجهاد شد محوري مبسطة.
- تدريب نموذج Random Forest للتنبؤ بعدد دورات التعب عند رفع ملف تجارب CSV مستوفٍ للأعمدة المطلوبة.

## حدود مهمة
- بيانات المواد داخل CSV تقريبية وتعليمية وليست مرجعاً تصميمياً.
- الموردون والمخزون والأسعار الحقيقية غير مدمجة بعد.
- لا يوجد نموذج لغة طبيعي متصل؛ وصف المشكلة في الوضع البسيط يمر عبر قواعد فرز مبسطة.
- لا يُصدر التطبيق اعتماداً هندسياً أو قرار سلامة.
- نموذج التعب لا يعمل إلا ببيانات تجريبية يرفعها المستخدم، ولا ينبغي استخدامه دون تحقق مستقل ومراجعة جودة البيانات.

## تنسيق ملف تجارب التعب
يجب أن يحتوي CSV على الأعمدة التالية:
`stress_mpa, ultimate_strength_mpa, yield_strength_mpa, temperature_c, stress_ratio, cycles_to_failure`

يُفضّل أن تشمل البيانات مواد وحالات تحميل متعددة، وأن يتم فصل بيانات الاختبار حسب العينات أو الدفعات لتجنب تسرب البيانات.
